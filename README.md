# SLM Performance Analytics Dashboard 

## Overview

The SLM Performance Analytics Dashboard is a Power BI based - Business intelligence solution designed to monitor warehouse operations inventory movement, manpower allocation, discrepancy management, and SIT ageing through interactive visualization and KPI tracking.
